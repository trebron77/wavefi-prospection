# Dossier d'accueil pour l'agent

Dépose ici les fichiers que tu veux me faire lire : spécifications, extraits de code,
captures de structure, jeux de données de test, notes de réunion, etc.

## Règles

- **Texte uniquement** : je ne lis pas les binaires (images, PDF, archives, `.docx`).
  Convertis-les en texte ou décris-les dans un `.md`.
- **Pas de secrets** : aucun `.env`, clé d'API, mot de passe ou jeton. Donne les *noms*
  de variables, jamais les valeurs.
- **Chemins relatifs au projet** : tout ce qui est hors du dossier du projet est refusé.

## Organisation suggérée

```
docs/
  specs/      # cahiers des charges, descriptions fonctionnelles
  data/       # jeux de données de test (JSON, CSV)
  notes/      # notes libres, comptes rendus
```

## Comment m'y faire regarder

Dis simplement : « regarde dans `docs/` » ou « lis `docs/specs/mon-fichier.md` ».
Je liste le dossier puis je lis ce qui est pertinent.
